# ⚡ Neovim Quick Reference Card

> Keep this open while you practice!

---

## 🎯 Survival Commands (Memorize These First!)

```
i          - Enter INSERT mode (start typing)
Esc        - Back to NORMAL mode (always do this first!)
:w         - Save file
:q         - Quit
:wq        - Save and quit
:q!        - Quit without saving (force)
```

---

## 🚶 Movement (NORMAL mode)

```
h j k l    - Left, Down, Up, Right
w          - Next word
b          - Previous word
0          - Start of line
$          - End of line
gg         - Top of file
G          - Bottom of file
```

---

## ✏️  Editing (NORMAL mode)

```
i          - Insert before cursor
a          - Insert after cursor
o          - New line below
dd         - Delete line
yy         - Copy line
p          - Paste
u          - Undo
Ctrl+r     - Redo
```

---

## 🗂️  LazyVim Essentials

```
Space      - Show all commands (leader key)
Space + e  - File explorer
Space + ff - Find files
Space + /  - Search in file
Space + ,  - Switch buffers
Space + gg - Open Git (Lazygit)
```

---

## 💻 Code Editing

```
gd         - Go to definition
K          - Show documentation
gcc        - Comment line
Space + ca - Code actions
Space + cf - Format code
```

---

## 🔍 Search

```
/text      - Search forward
n          - Next match
N          - Previous match
```

---

## 📋 Visual Mode (Select Text)

```
v          - Start visual mode
(move to select)
y          - Copy selection
d          - Delete selection
```

---

## 🪟 Windows

```
Ctrl + h   - Move left
Ctrl + j   - Move down
Ctrl + k   - Move up
Ctrl + l   - Move right
```

---

## 🆘 Help

```
:Tutor           - Interactive Neovim tutorial
Space + ?        - Show all keybindings
:help <topic>    - Help on any topic
```

---

## 🎯 Daily Practice (Week 1)

**Monday**: Master `hjkl` movement
**Tuesday**: Practice `i`, `o`, `dd`, `yy`, `p`
**Wednesday**: Learn `Space + e` and `Space + ff`
**Thursday**: Try `w`, `b`, `0`, `$`
**Friday**: Practice visual mode with `v`
**Weekend**: Put it all together!

---

## 💡 Remember

1. **Press Esc first** - If stuck, press Esc multiple times
2. **One command per day** - Don't overwhelm yourself
3. **Practice 15 min daily** - Better than cramming
4. **Use :Tutor** - Built-in interactive tutorial
